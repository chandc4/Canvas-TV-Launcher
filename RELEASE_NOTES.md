# Canvas TV Launcher — Release Notes

## Version
1.0.0 (debug build currently; release build ready for signing)

## Highlights
- Rebranded from neuhome to Canvas TV Launcher
- Clean ambient canvas home screen
- Tiny configurable app dock (0–10 apps)
- Phone-to-TV wallpaper and video transfer via local web hub
- Wallpaper rotation and dim controls
- App drawer via D-pad Down
- Safe-mode/recovery guidance in Settings
- Free-space check before uploads

## Recovery
If the launcher fails to start, open TV System Settings → Apps → Default apps/Home app and select the stock launcher. You can also reboot and switch there.

## Known limitations
- Rotation timing is best-effort.
- Very large images can increase memory use.
- Release builds require your own signing key.
